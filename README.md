## Visualiser

Website to show visual walkthough of several well-known algorithms with randomised inputs that can dynamically change.

## How to download

Download code, run 'npm install' or any other package manager alternative.

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
